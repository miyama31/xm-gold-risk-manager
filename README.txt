XM GOLD PWA 公開用ファイル

GitHubで新規のPublicリポジトリを作成し、このフォルダ内の index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png をリポジトリのルートにアップロードします。
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
公開URLが表示されたらiPhone Safariで開き、共有 → ホーム画面に追加。PCはChrome/Edgeで同じURLを開きます。

注意: 公開されるソースコードに口座番号や個人情報を入れないでください。残高・履歴は各端末のブラウザ内のみ保存され、自動同期されません。為替レートは参考値でリアルタイムではありません。
